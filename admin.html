Editor statis, bukan admin privat. GitHub Pages tidak menyediakan login atau penyimpanan perubahan. Edit di sini hanya di browser ini; setelah selesai, unduh catalog.json, gantikan file di repository, lalu commit/push. Semua nomor pembayaran dan gambar yang dimasukkan ke katalog akan tampil secara publik—jangan masukkan kata sandi atau data rahasia.

Metode pembayaran (opsional)

Isi hanya jika setuju rincian pembayaran tampil untuk semua pengunjung. Ini tidak membuat pembayaran otomatis.

Opsional. JPG, PNG, WebP maksimal 500 KB. QRIS dan nomor yang diunggah akan tersedia bagi publik.
